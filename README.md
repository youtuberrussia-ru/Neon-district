# NEON DISTRICT — версия 0.1 (прототип)

Городской симулятор на Godot 4.3 (GDScript), портретная ориентация, Android в первую очередь.

## Что уже есть
- Карта 12×12 с неоновой сеткой
- Камера: перетаскивание пальцем, зум щипком (на ПК — колесо мыши)
- 5 типов зданий: Дом, Магазин, Завод, Электростанция, Небоскрёб
- Строительство тапом по клетке, снос с возвратом 50% стоимости
- Доход начисляется каждую секунду, офлайн-доход до 2 часов
- Автосохранение (каждые 10 сек и при сворачивании игры)

## Как запустить
1. Установить Godot 4.3+ (бесплатно, godotengine.org).
2. Project Manager → Import → выбрать `project.godot`.
3. Нажать F5.

## Структура
- `project.godot` — настройки проекта (1080×1920, autoload `GameState`)
- `scenes/main.tscn` — главная сцена
- `scripts/game_state.gd` — деньги, здания, доход, сохранение
- `scripts/main.gd` — отрисовка, камера, ввод, интерфейс

## Сборка APK на GitHub
1. Загрузить проект в репозиторий (ветка `main`).
2. Вкладка **Actions** → **Build Android APK** → **Run workflow** (или просто сделать коммит).
3. Когда сборка закончится, APK лежит в **Artifacts** → `neon-district-apk` (внутри zip).
4. Скачать на телефон, распаковать и установить (разрешить установку из неизвестных источников).
